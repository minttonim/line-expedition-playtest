# 라인 원정대 · 퍼즐 플레이테스트

모바일 브라우저로 플레이할 수 있는 판타지 퍼즐 게임 프로토타입입니다.

준비 페이즈에서 판을 배치하고, 본페이즈 60초 동안 매치·족보·스킬·피버로 몬스터를 공격합니다.

게임 기록은 각 플레이어의 브라우저에만 저장됩니다.


액션 74: 불·물·풀·빛·어둠·서리의 동료 6명 중 3명을 편성합니다. 선택한 리더의 준비 스킬은 준비 시작 시 한 번 자동 발동합니다. 전투 스킬은 초당 3%, 자기 속성 돌 제거당 8%로 충전됩니다. 스킬이 직접 제거한 돌은 시전자 자신을 충전하지 않습니다.

| 동료 | 준비 리더 스킬 | 전투 스킬 |
|---|---|---|
| 기사 · 불 | 무작위 돌 2개를 불로 | 불 블록 전체 제거 |
| 마법사 · 물 | 무작위 돌 2개를 물로 | 무작위 세로 물결 제거 |
| 정찰병 · 풀 | 무작위 가로 한 줄 정렬 | 무작위 세로 관통 제거 |
| 사제 · 빛 | 무작위 가로 연속 3칸을 빛으로 | 무작위 십자 제거 |
| 주술사 · 어둠 | 무작위 돌 3개를 어둠으로 | 무작위 3×3 제거 |
| 수호자 · 서리 | 무작위 세로 한 줄 정렬 | 무작위 가로 한 줄 제거 |

로컬 검증: `node --test tests/*.test.mjs`

액션 76: 새 3명은 준비·전투 각각 4프레임 투명 PNG 스프라이트로 발동 연출을 재생합니다. 전용 컷인은 손·무기 구조와 서로 다른 포즈를 반영한 별도 원화 v2를 사용합니다.
